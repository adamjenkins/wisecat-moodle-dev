# Core hook catalogue (Moodle 5.2 and 5.3)

Read this when you need to know whether core has a hook for an action, its exact class name, what its
constructor takes and what a callback can call on it.

Generated by reading every class under a `classes/hook/` directory of the standard components in the 5.2 and
5.3.0 source (`public/**/classes/hook/*.php`, standard plugins only, per `lib/plugins.json`). Not run. "5.3+"
marks a hook that does not exist on 5.2; every other hook exists on both. Constructor arguments are
`public readonly` properties of the hook, so `$hook->course`, `$hook->userids` and so on are readable in a
callback; the Methods column lists what a callback can call beyond that. "Stoppable" hooks implement
`\Psr\EventDispatcher\StoppableEventInterface`: a callback may call `$hook->stop_propagation()` and no later
callback runs.

To check a hook on a site: Site administration > Development > Hooks overview (`/admin/hooks.php`) lists every
discovered hook and the callbacks registered for it.

| `before_standard_head_html_generation` | `before_standard_html_head` | `(\renderer_base $renderer, string $output = '')` | `add_html()`, `get_output()` |
| `before_standard_top_of_body_html_generation` | `before_standard_top_of_body_html` | same | `add_html()`, `get_output()` |
| `after_standard_main_region_html_generation` | `standard_after_main_region_html` | same | `add_html()`, `get_output()` |
| `before_standard_footer_html_generation` | `standard_footer_html` | same | `add_html()`, `get_output()` |
| `before_footer_html_generation` | `before_footer` | same | `add_html()`, `get_output()` |

Stopping a "before ... deleted" hook does not always veto the deletion; each dispatch site decides. In 5.3.0
`\core_ai\manager` skips the delete when `before_provider_deleted` was stopped (`public/ai/classes/manager.php`),
while `enrol_plugin::delete_instance()` ignores the stop on `before_enrol_instance_deleted` and deletes anyway
(`public/lib/enrollib.php`). Read the dispatch site before relying on a veto.

## Keeping this list current

Regenerate it for a new Moodle version by listing `public/**/classes/hook/*.php` in the new tree and diffing the
class names against this file; `replaces_callbacks` attributes show which legacy callbacks each new hook retires.
